ادخل للوحة التحكم

الصق رمز GitHub الخاص بيك. ينحفظ بهذا المتصفح بس، وما يطّلع عليه أحد.

شلون أطلع الرمز؟
  1. افتح صفحة إنشاء رمز جديد بـ GitHub
  2. Token name (اسم الرمز): اكتب لوحة الموقع
  3. Expiration (الانتهاء): اختار أطول مدة موجودة
  4. Repository access: اختار Only select repositories وبعدها اختار مستودع موقعك
  5. Permissions ← Repository permissions ← Contents: اختار Read and write
  6. اضغط Generate token، وانسخ الرمز (يبدي بـ github_pat_) والصقه فوق
